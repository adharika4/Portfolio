# Adharika Mahajan — Portfolio

A personal portfolio showcasing my background in computer science and AI, selected projects, research publication, skills, and achievements.

**[View the portfolio](https://adharika4.github.io/Portfolio/)**

## Features

- Responsive layouts for desktop, tablet, and mobile
- Light and dark themes with saved preferences
- Smooth navigation, project filters, and interactive project details
- Contact section with email, LinkedIn, and GitHub links

## Built with

HTML, CSS, JavaScript, and Poppins.

## Run locally

Clone or download this repository and open `index.html` in your browser. No installation or build step is required.

## Deployment

Hosted on GitHub Pages. Updates pushed to the `main` branch are published automatically.

Poppins is included under the [SIL Open Font License](assets/fonts/OFL.txt).
